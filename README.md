# Movie-app
# 🎬 Movie Zone

A responsive **Movie App** built using **HTML**, **CSS**, **Bootstrap** and **JavaScript**. Movies are displayed dynamically on the page, and users can filter them by genre with a single click.

---

## 🔗 Live Demo

👉 **[https://movie-app-sneha.netlify.app](https://movie-app-sneha.netlify.app)**

---

## ✨ Features

- Dark themed, clean movie listing page
- Genre filter buttons: **All, Action, Thriller, Animation, Horror, Drama, Sci-Fi**
- Movies rendered dynamically using JavaScript DOM manipulation
- Responsive layout using Bootstrap 5
- Lightweight, no build tools needed

---

## 🛠️ Tech Stack

| Technology | Use |
|------------|-----|
| HTML5 | Page structure |
| CSS3 | Custom styling |
| Bootstrap 5.3 | Responsive layout and buttons |
| JavaScript (ES6) | Dynamic rendering and genre filtering |
| Netlify | Deployment |

## 🚀 How to Run Locally

1. Clone the repository
   ```bash
   git clone https://github.com/sneha-goyal7/Movie-app.git
   ```
2. Open the project folder
   ```bash
   cd Movie-app
   ```
3. Open `index.html` in your browser (or use **Live Server** in VS Code)
